# CFresh Mart – Website and Digital Ordering Project

## About the Project

CFresh Mart is a family-run fish retail business based in Chennai, India. I worked on developing a simple digital presence for the business to make it easier for customers to learn about the products and access the ordering process online.

The project was created as a practical application of my software development and data/technology skills to a real business environment.

## What I Worked On

My contribution to the project included:

* Developing and organising the website structure
* Creating the pages and user interface for the business
* Presenting information about CFresh Mart and its products
* Designing a simple and easy-to-use customer journey
* Supporting the digital ordering workflow
* Testing the website and making improvements to the user experience
* Organising the project files and maintaining the source code in GitHub

The focus was on keeping the website straightforward and practical for a local retail business rather than building an unnecessarily complex system.

## Development Approach

I approached the project from a practical business perspective. The aim was to create a clear online presence and make the customer journey as simple as possible.

Rather than treating the project only as a coding exercise, I considered how a customer would find information about the business, view the available products and proceed towards making an enquiry or order.

## Why I Created This Project

Working on CFresh Mart gave me an opportunity to apply my technical knowledge to a real-world business use case.

It also allowed me to work across different parts of a project, including website development, user experience, content organisation, testing and maintaining the project using version control.
